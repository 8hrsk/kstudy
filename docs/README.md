# Как проект пришёл к нынешнему виду

Четыре разбора в порядке появления. Каждый следующий отменяет часть выводов
предыдущего — это не редакционная небрежность, а собственно ход работы.
Оставлены целиком, включая отброшенные ветки: знать, почему что-то НЕ делается,
обычно полезнее, чем знать, что делается.

### 1. [bio-slm-critique.md](bio-slm-critique.md)
Исходная идея: биологически вдохновлённая сеть, растящая нейроны в реальном
времени, по мотивам [Axicor](https://github.com/H4V1K-dev/axicor).

Чем закончилось: SNN для языка отброшен (даёт выигрыш только на нейроморфном
железе); нейрогенез перенесён из языкового ядра в подсистему памяти —
у взрослого человека новые нейроны появляются практически только в гиппокампе,
и их функция это паттерн-сепарация в эпизодической памяти, а не мышление.

### 2. [expert-model-pipeline.md](expert-model-pipeline.md)
Переформулировка: экспертная модель из корпуса документации.

Чем закончилось: «модель читает и запоминает» — не то, как работает обучение
(AdaptLLM: сырой корпус ломает способность отвечать; EntiGraph: факту нужны
сотни представлений). Забывание не освобождает ёмкость: трансформер хранит
~2 бита на параметр, и домен туда влезает без всякой чистки. Узкое место —
число повторений, а не место.

### 3. [self-bootstrapping-limits.md](self-bootstrapping-limits.md)
Возражение: разве модель не может учить себя сама, без более сильной модели?

Чем закончилось: может — если петлю замыкает **верификатор**, а не она сама.
Нужен либо более сильный генератор, либо сильный верификатор; одно из двух.
Заземление каждого сэмпла на источник выводит систему из режима model collapse.

### 4. [research-program.md](research-program.md)
Механизм и программа. Чем человек заменяет проверку, читая теорию: предсказание
и его ошибка, согласованность с известным, способность восстановить, способность
инстанцировать. Все четыре вычислимы.

Отсюда стенд Э1 в корне репозитория — и главный эксперимент: прогнать пайплайн
на верифицируемом домене дважды, с компилятором и без, чтобы получить число,
какую долю настоящего верификатора добирает проверка без эталона.

---

**Важно:** раздел 5 в `research-program.md` предлагает метрику
`выигрыш = L(C) − L(N) − L(C|N)`. Она не пережила первого прогона тестов:
поверхностный MDL структурно поощряет копирование. Действующая версия — закрытый
экзамен, см. [README](../README.md), раздел «Две находки стенда».
